## 📖 Descripción

Este proyecto consiste en una práctica de lógica con ejercicios de comparación de números, conversor de temperatura y encontrar el factorial de un número

---

## ✨ Características

- Comparar números.
- Conversor de temperatura.
- Factorial de un número.
